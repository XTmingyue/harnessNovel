# HarnessNovel Web Brand Spec

## Mode

Redesign preserve. The existing CLI workflow, workspace layout, task service and file APIs remain unchanged while the Web interface moves from an all-in-one control panel to a staged writing wizard.

## Assets

- Primary mark: `webui/static/logo.svg`, the open “汉” glyph used beside the wordmark
- Compact mark: `webui/static/favicon.svg`, the same glyph in a rounded container for small square placements
- README mark: `docs/logo.svg`, identical to the compact mark
- Web wordmark: live text (`harnessNovel`); `h`, `a`, and `N` use the mint accent and heavier weight
- README wordmark: `docs/wordmark-light.svg` and `docs/wordmark-dark.svg`, selected by color scheme

## Visual System

- Canvas: `#F5F8F6`
- Surface: `#FFFFFF`
- Ink: `#1B2824`
- Primary action: `#0B7769`
- Secondary accent: `#C7583F`
- Warm signal: `#B8842B`
- Display type: `Songti SC`, `Noto Serif SC`, serif fallback
- Body type: `PingFang SC`, `Hiragino Sans GB`, sans-serif fallback
- Code type: `SFMono-Regular`, `Menlo`, monospace
- Spacing: 8px base unit
- Radius: 6px for controls and panels
- Motion: 160-220ms ease-out; reduced-motion safe
