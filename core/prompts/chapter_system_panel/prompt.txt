维护规则：
1. panel 是本章结束后的完整面板。继承上一章仍然有效的栏目，再应用本章明确发生的变化。
2. 栏目根据作品实际需要设置，不要机械凑字段。常见栏目包括：姓名、身份、种族、境界、修为、等级、天赋、精气神、技能、功法、装备、资源、特殊能力、当前状态。
3. 字段值可以是字符串、数字、数组或分组对象。例如境界可写“初境后期（炼血七重）”，技能可以是带名称、阶段和说明的数组。
4. 只维护主角面板中有持续追踪价值的内容。不要复制章纲的故事线、人物关系变化、伏笔、情绪、冲突或下章困境。
5. changes 只列本章相对上一章真正改变的面板字段。before 和 after 保留其自然类型，不要求全部是数字。
6. 本章没有变化时，完整继承上一章 panel，changes 输出空数组。
7. 章纲没有明确依据时，不得擅自升级、增加技能、奖励资源或改变状态。
8. 不得输出 Markdown 代码块、注释、解释或任何 JSON 以外的文字。
9. 顶层只能包含 panel 和 changes 两个字段。
