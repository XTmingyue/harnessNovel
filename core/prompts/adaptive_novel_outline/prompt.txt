【设计原则】
1. 先服务核心玩法，再考虑情节安排。每个舞台都必须能展示核心玩法的不同侧面。
2. 全书必须有一条贯穿所有舞台的长线主线：埋悬念、造期待、不断给读者“还有更大秘密”的感觉。
3. 每个舞台内部必须有多条短线：短目标、短危机、短反转、短爽点、短收获、短钩子，用于持续刺激情绪。
4. 角色不是名单，而是运行在舞台里的功能系统：制造压迫、见证主角、提供资源、背叛/绑定、推动伏笔。
5. 参考小说只能提供节奏和结构功能。不得把参考小说具体人物、地点、历史事件、宗教体系、任务目标换名搬运。
6. 如果目标世界资料与参考小说冲突，以用户方向、核心玩法和目标世界资料为准。
7. 允许不同于参考小说的舞台、角色和事件，只要爽点密度、长线期待和情绪推进更适合新书。

【输出格式】
使用纯文本输出，标题使用 # 标记，禁止 Markdown 表格。段落之间用空行分隔。

# 一、作品定位与核心玩法
题材类型、目标读者、核心卖点、主角破局方式、读者追读循环。

# 二、全书长线主线
写清贯穿全书的大悬念、大目标、大对手或大因果。说明它如何分阶段暴露，哪些真相不能提前揭露。

# 三、舞台路线总览
按“舞台/副本”而不是传统流水账设计全书。每个舞台写：舞台名称、阶段功能、玩法价值、舞台规则、主要资源、主要压力、结束状态、后患钩子。

# 四、角色系统与成长线
设计主角、核心伙伴、重要对手、见证者、资源型角色、情绪刺激型角色。每个重要角色写：功能位、初始欲望、与主角关系变化、成长线、情感线、不能提前揭露的信息。

# 五、分卷/阶段设计
按卷或阶段组织大纲。每卷必须包含：本卷舞台、本卷长线推进、本卷短线组合、本卷主要爽点、本卷结尾钩子、本卷主角状态变化。

# 六、舞台内短线模板
说明每个舞台内可以反复使用的短线结构，例如小危机、误会、打脸、资源争夺、规则破解、身份压迫、情感拉扯、伏笔回收。

# 七、伏笔与信息差总表
列出 8-12 条长线伏笔。每条写：谁知道、谁不知道、读者知道到什么程度、何时暗示、何时阶段性回收。

# 八、成长体系与资源循环
设计主角从弱到强的路径。包括能力成长、资源成长、身份成长、认知成长、关系成长和代价累积。

# 九、参考结构转译边界
说明参考小说中哪些只是节奏功能，不能继承具体设定；哪些结构功能可以转译进新书。
