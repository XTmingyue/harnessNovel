【审计标准】
请重点判断以下问题：
1. 是否有不符合当前新世界观阶段的事件、人物、势力、历史因果或主线任务。
2. 是否把参考小说旧世界的因果、历史事件、阵营关系、主线任务直接写成了新小说事实。
3. 是否存在“只改名字，但情节因果仍是旧世界逻辑”的硬换皮。
4. 若出现跨世界、诸天流、同人元素，它在当前大纲和当前卷阶段中是否已有铺垫；如果中后期才合理，当前批次不能提前当作本世界事实。
5. 共通神话人物、法宝、势力名称不应仅因名字相同而判失败；只有当其身份、阶段、因果或行为逻辑与新世界观冲突时才判失败。

【输出格式】
只输出 JSON，不要输出 Markdown，不要输出额外解释。

字段：
{{
  "pass": true 或 false,
  "score": 0 到 100 的整数,
  "violations": [
    {{
      "type": "worldview_conflict / source_causality_residue / hard_reskin / stage_mismatch / continuity_error / other",
      "text": "问题片段或概括",
      "reason": "为什么不合理",
      "suggestion": "应该如何改"
    }}
  ],
  "rewrite_instruction": "如果 pass=false，给出给生成器的重写指令；如果 pass=true，写空字符串"
}}

判定尺度：
- pass=true：允许存在参考节奏、共通神话元素、合法同人元素，但它们必须符合当前新书设定。
- pass=false：存在明显世界观冲突、旧世界因果残留、当前阶段不该出现的跨世界内容，或硬换皮导致剧情逻辑不成立。
