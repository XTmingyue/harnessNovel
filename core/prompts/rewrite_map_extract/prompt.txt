【生成要求】
请重点提炼以下类型的映射：
1. 高风险世界观映射：宗教体系、势力体系、历史事件、时间线、神话因果。
2. 关键人物映射：主角、核心配角、导师、反派、功能性角色。
3. 关键地点映射：修行地、主地图、封印地、秘境、势力据点。
4. 关键物品映射：法宝、功法、丹药、特殊资源。
5. 关键事件映射：拜师、假主线、陷阱、镇压、突破、收服、背叛、伏笔回收。
6. 必须删除或功能替代的源情节：目标世界无自然对应物时，不要硬换皮。

【输出格式】
按以下格式输出，每个映射独立成段：

【映射N】
源元素：参考小说中的人物/事件/地点/物品/设定
源情节功能：该元素在参考小说中承担什么功能
目标元素：新小说中的对应元素，若无自然对应物，写“无直接对应”
处理方式：直接映射 / 功能替代 / 合并 / 删除 / 延后
适用范围：全书 / 某卷 / 某章节范围 / 某类场景
禁止残留参考元素：列出后续生成中不得直接出现的参考词
合理性风险：说明硬换皮可能造成的不合理之处
后续生成约束：后续批次摘要、章纲、正文必须如何处理

必须特别标出“目标世界无自然对应物”的源情节，并给出功能替代方案。
使用纯文本输出，禁止使用 Markdown 格式符号（如 *、**、-、>、| 等）。标题使用 # 标记。
